# Цитата дня

Небольшое адаптивное React-приложение с короткими цитатами из философских текстов, фильмов, сериалов и аниме. У каждой записи указаны автор, произведение, место в произведении, контекст и ссылка для проверки атрибуции.

**Демо:** https://pewo4ever.github.io/Quote-of-Day/ (появится после включения GitHub Pages и первого успешного запуска workflow).

## Возможности

- Цитата выбирается случайно при первом открытии календарной даты и сохраняется в браузере.
- Можно переходить по датам назад и вернуться к сегодняшней цитате; для завтрашнего дня показана заглушка.
- Поиск работает по цитате, автору, названию, месту и контексту.
- Избранное и настройка размера текста сохраняются локально.
- Интерфейс адаптируется к мобильному и широкому экрану; основные элементы доступны с клавиатуры.

## Запуск на своём компьютере

Установите Node.js 22.12+ (или 20.19+) и Git. В терминале из папки проекта выполните:

```sh
npm install
npm run dev
```

Vite покажет локальный адрес приложения, обычно `http://localhost:5173`.

## Проверки перед публикацией

```sh
npm test
npm run lint
npm run build
```

Последняя команда создаёт production-сборку в `dist/`. После локальной проверки основных сценариев также можно открыть эту сборку командой `npm run preview`.

При каждом push в ветку `main` GitHub Actions автоматически запустит тесты, ESLint, production-сборку и публикацию на GitHub Pages.

### Включение GitHub Pages

1. Отправьте проект в репозиторий GitHub в ветку `main`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите источник **GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь успешного завершения `Deploy to GitHub Pages`.
5. Откройте ссылку из раздела **Settings → Pages**. Последующие push в `main` будут обновлять сайт автоматически.

## Как устроено

- React 19 управляет интерфейсом; Vite запускает локальный сервер и собирает приложение.
- `src/App.jsx` соединяет экраны, выбранную дату, избранное и настройки.
- `src/components/` содержит карточку, нижнюю навигацию, библиотеку поиска и экран настроек.
- `src/data/quotesData.js` хранит каталог и редакторский контекст записей.
- `src/utils/date.js` работает с календарными датами; `quoteStorage.js` хранит назначения цитат и избранное; `preferencesStorage.js` сохраняет пользовательские предпочтения.
- `src/data/quotesData.test.js` проверяет каталог, календарь и работу хранилища, включая повреждённые данные и недоступное хранилище браузера.
- `.github/workflows/deploy.yml` запускает проверки и публикует production-сборку.

## Быстрая ручная проверка в браузере

1. На главной нажмите «Вчера», затем «Завтра» и «Вернуться к сегодняшней цитате»: должна открыться сегодняшняя дата, а не вчерашняя.
2. Добавьте цитату в избранное, перейдите в «Избранное», обновите страницу и убедитесь, что она осталась там; затем уберите её.
3. Найдите цитату по имени автора, проверьте сообщение для пустого результата поиска.
4. Измените размер текста в настройках, обновите страницу и убедитесь, что настройка сохранилась.
5. Пройдите те же действия клавишей Tab и проверьте расположение карточек на узком экране.

## Источники и переводы

В каталоге указаны ссылки на Wikisource и Wikiquote для сверки текста и контекста. Русские формулировки помечены как переводы для приложения и не выдаются за опубликованный перевод конкретного издания. Популярное изречение о «совершенстве как привычке» удалено: это позднее резюме идей Аристотеля, а не его дословная цитата.

Диалоги из современных произведений даны короткими фрагментами и атрибутированы; наличие ссылки и атрибуции само по себе не означает, что текст свободен от авторских прав. Перед коммерческим использованием каталога отдельно проверьте права и условия применимого законодательства.

## Ограничения первой версии

- `localStorage` действует только в текущем браузере и на текущем устройстве. Очистка данных браузера удалит избранное и историю назначений.
- Разные пользователи могут получить разные цитаты на одну дату. Общего расписания и синхронизации между устройствами пока нет.
- Каталог небольшой и собирается вручную; ссылки помогают проверять атрибуцию, но не заменяют редакторскую проверку перевода.
- Экран истории, API, сервер и аккаунты пользователей пока не входят в первую версию.
